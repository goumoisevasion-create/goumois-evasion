Les 3 parcours sur le Doubs

Idéal pour les débutants. Eaux calmes, magnifiques panoramas sur les gorges du Doubs franco-suisse.
6 km 1h30 Niveau 1 – Débutant
● Disponible 8 kayaks dispo
Parcours Intermédiaire — Les Gorges
Rapides de classe 2, rochers sculptés. Paysages exceptionnels des gorges franco-suisses. Idéal pour les familles sportives.
